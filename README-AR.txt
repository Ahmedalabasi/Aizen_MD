المتطلبات:
- Node.js 20 أو أحدث (يفضل Node.js 22).
- استضافة تسمح بتشغيل Node.js باستمرار.

التثبيت على Wispbyte:
1) ارفع جميع محتويات هذا المجلد مباشرة إلى /home/container.
2) تأكد أن index.js و package.json في جذر الخادم، وليس داخل مجلد فرعي.
3) نفّذ npm install.
4) شغّل npm start.
5) عند أول تشغيل سيظهر رقم الحساب ورمز الاقتران في Console.
6) لا تحذف مجلد session بعد نجاح الربط.

الأوضاع والصلاحيات:
- الوضع العام: يستقبل أوامر المستخدمين.
- الوضع الخاص: يستقبل الأوامر أيضاً؛ أوامر المالك الحساسة مثل تغيير الوضع والصيانة والبث وإعادة التشغيل والإحصائيات والسجلات تظل محمية برقم المالك أو حساب البوت.
- أوامر إدارة المجموعة تتطلب أن يكون مرسل الأمر مشرفاً أو المالك، وأن يكون البوت مشرفاً لتنفيذ إجراءات واتساب التي تتطلب ذلك.

الوظائف الخارجية:
- الذكاء الاصطناعي: يعتمد على algochat-ai أو خدمة Pollinations المجانية؛ التوفر والاستجابة غير مضمونين.
- التصميم: يعتمد على Pollinations، ويتطلب اتصال إنترنت.
- تنزيل TikTok وInstagram والفيديو والصوت: يعتمد على Cobalt API العام. قد تتغير الخدمة أو تضع حدوداً أو ترفض بعض الروابط.
- البحث عن الفيديو: يعتمد على yt-search. بحث GitHub يعتمد على GitHub API، والبحث العام .جوجل في هذه النسخة يعتمد على ويكيبيديا العربية.
- تنزيل الملفات محدود بحجم 45MB.
- مشاهدة الحالات والتفاعل معها يعتمدان على دعم إصدار Baileys وواتساب؛ يجب اختباره على الحساب بعد الربط.

الحماية:
- منع التكرار: ثلاث رسائل متطابقة خلال نافذة 30 ثانية.
- منع الفيضان: خمس رسائل خلال 10 ثوانٍ.
- كتم العضو: يحذف رسائله أثناء الكتم ولا يطرده.
- الطرد/الحظر والتحذيرات وإدارة المجموعة تتطلب صلاحيات مناسبة.

ملاحظات:
- لا يمكن ضمان عمل خدمات الطرف الثالث أو نجاح الاقتران من داخل الكود وحده.
- لا يمكن ضمان نسبة CPU ثابتة؛ تم الإبقاء على التخزين المؤجل وحدود الذاكرة المؤقتة والسجلات.
- نفّذ npm run check لفحص صياغة ملفات JavaScript.

تقسيم الأقسام:
- كل قسم من الأقسام العشرة موجود في ملف مستقل داخل sections/.
- sections/index.js يجمع ملفات الأقسام، وmenu.js ينسق عرضها، ويستدعيه index.js.
- منطق أوامر الحالات موجود مع ملف sections/status.js.

الحالات:
- عند أول اتصال: مشاهدة الحالات والتفاعل العشوائي مفعّلان تلقائياً.
- مشاهدة_تشغيل / مشاهدة_ايقاف يتحكمان بالمشاهدة فقط.
- تفاعل_تشغيل / تفاعل_ايقاف يتحكمان بالتفاعل فقط.
